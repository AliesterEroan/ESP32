## 🚀 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/AliesterEroan/ESP32.git
   ```

2. **Open a project folder**
   - Each project has its own folder with `.ino` file
   - Check the individual README for specific instructions

3. **Install required libraries**
   - Open Arduino IDE
   - Go to Sketch → Include Library → Manage Libraries
   - Search for and install the required libraries

4. **Upload to your ESP32**
   - Connect your ESP32 via USB
   - Select your board in Tools → Board
   - Select the correct port
   - Click Upload!
